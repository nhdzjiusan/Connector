# 外设电量 · 液态玻璃界面规范

适用于 Windows 托盘弹窗 1.1。布局单位为 DIP，96 DPI 下 1 DIP 等于 1 屏幕像素。设备名称、百分比及电源状态是最高优先级内容。配套源文件为 GlassMaterial.cs、BatteryPanel.cs、TrayArt.cs。

## 一、合成顺序

| 从后到前 | 输入与职责 | 实现位置 |
| --- | --- | --- |
| 折射背景 | 以窗口归一化坐标生成青、蓝、紫渐变及细窄的斜向波纹，作为可采样纹理。窗口移动时纹理随窗移动。 | GlassMaterial.Backdrop |
| 玻璃层 | 根据窗口、标题、操作区、设备和设置区的有符号距离场，在背景纹理上做双界面采样。叠加材质底色、内阴影及表面高光。 | GlassMaterial.Render |
| 交互光 | 光标位于弹窗内时，在其下绘制局部渐隐的椭圆光斑。 | BatteryPanel.OnPaintBackground |
| 内容层 | 最后绘制图标、文字、电量条和可聚焦控件。所有文字及状态图标使用原始坐标和单色边缘。 | DeviceCard.OnPaint 与窗体控件 |

此版本的背景来自应用内生成纹理。移植至拥有合成器背景纹理的宿主时，可替换 Backdrop.Sample，沿用镜片坐标、曲率和内容层。

## 三、距离场、双界面折射与色散

以下是当前 CPU 渲染器采用的近轴屏幕空间近似。p 为采样点，c 为圆角矩形中心，b 为半尺寸，r 为圆角半径。负距离表示镜片内部。

    q = abs(p - c) - (b - r)
    d = length(max(q, 0)) + min(max(q.x, q.y), 0) - r
    h = max(14 - abs(d1 - d2), 0) / 14
    dJoined = min(d1, d2) - 3.5 * h²
    n = normalize(d(p + (1,0)) - d(p - (1,0)),
                  d(p + (0,1)) - d(p - (0,1)))
    z = max(0, -d)

标题、刷新按钮共用 dJoined 求法线、折射和高光。其各自点击区域仍独立。设备之间保留独立轮廓。零长度梯度使用零法线。

| 光学变化 | 参数与采样含义 |
| --- | --- |
| 中心微放大 | 在离边缘至少 12 DIP 处，将源坐标朝中心拉回 1.8%，对应约 1.018 倍视觉放大。 |
| 内缘压缩 | 前表面在深度 5 DIP 附近加入负向曲率，带宽参数为 3 DIP。 |
| 外缘翻卷 | 前表面边缘正向曲率为 0.62，衰减长度 3 DIP。背面反向曲率为 −0.42，衰减长度 4 DIP，形成方向变化的窄边。 |
| 双界面 | 折射率 1.46。先估算空气进入玻璃的方向及背面交点，再在该交点重新求法线并估算玻璃出射方向。 |
| 色散 | 沿局部外法线采样，R 偏移 +1.5、G 取 0、B 偏移 −1.5 个物理像素。两端通道在轮廓处相距最多 3 像素。向内按 exp(−z/4) 衰减。 |

可直接移植的采样流程如下。法线采样、两次命中位置及双线性纹理过滤均须保留。scale 为设备 DPI / 96。

    front = 0.62 * exp(-z/3) - 0.27 * exp(-((z-5)/3)²)
    inside = (1 - 1/1.46) * front * n
    hit = p + 11 * inside
    back = -0.42 * exp(-max(0,-d(hit))/4) * normal(hit)
    outgoing = 1.46 * inside + (1 - 1.46) * back
    uv = hit + 12 * outgoing - 0.018 * (p-c) * clamp(z/12, 0, 1)
    split = (1.5/scale) * exp(-z/4) * n
    rgb = (sample(uv+split).r, sample(uv).g, sample(uv-split).b)

纹理采样坐标钳制到纹理边缘。合并区 x > 310 时，中心放大以刷新胶囊中心为参考。阴影及反射在折射后合成。主光从左上方入射，亮度因子 L = clamp(−0.48 nx − 0.88 ny, 0, 1)。内阴影位于深度 3.5 DIP，宽度参数 2.3，衰减幅度为 3.5% + 8% × (1−L)。高光中心位于 0.9 DIP，宽度参数 0.95，向 #F8FFFF 混合 14% + 57% × L。两者均以 exp(−((z−中心)/宽度)²) 调制。

## 四、主题与交互

| 色彩或状态 | 浅色 | 深色 |
| --- | --- | --- |
| 源纹理蓝 / 青 / 紫 | #A0C1ED / #72D3D0 / #CFAEE1 | #233561 / #0F6C7B / #573C82 |
| 玻璃底色及设备卡片混合量 | #F9FDFF，72% | #152238，75% |
| 顶层文字 / 次级文字 | #142941 / #3D536B | #F1F8FF / #BED0E3 |
| 常规 / ≤40% / ≤20% | #006F5B / #8D5210 / #B1333F | #95EED1 / #FFD494 / #FFACB7 |
| 充电或参考电量 | #2851C1，优先于低电量色 | #A1D1FF，优先于低电量色 |

外壳与底色仅混合 21%，卡片有较高底色比例，为文字提供稳定底衬。设备图标使用鼠标、键盘、耳机三种轮廓。百分比使用 Segoe UI Bold 24 px，名称为 Microsoft YaHei UI Bold 13 px，设备说明为 10.5 px。字体尺寸在逻辑坐标中定义，随系统 DPI 缩放。

读取 Windows 应用颜色模式 AppsUseLightTheme。弹窗打开时及接到系统设置或主题变化消息时复核。光标光斑为 180 × 128 DIP，中心色 #E1F9FF，中心透明度浅色 32/255、深色 20/255，边缘衰减至透明。按钮悬停与按下分别叠加透明度为 25/255、52/255 的冷色。在弹窗可见时每 40 ms 检查一次光标，位置改变才重绘。弹窗隐藏即停止光影计时器。动态光仅合成在缓存材质之上。

## 五、落地验收

1. 用相同三条设备数据对照两套主题。卡片大百分比和小字均应清晰，100% 电量条到达末端，0% 时仅显示轨道。
2. 检查标题与刷新胶囊交接处。高光沿外轮廓连续行进，接缝内部没有重复描边。对折射纹理放大观察时，色边应集中在轮廓附近。
3. 在设备卡片上横移光标，亮斑随位置微调。保持光标静止或关闭弹窗后，光影不应持续重绘。
4. 检查零、一、三、五台以上设备。滚动后各行底材应对齐图标和进度条。设备离线及重新上线时检查行数、窗口高度和托盘图标。
5. 使用键盘操作刷新、退出、5 和 15 分钟两端值及登录启动。接电参考读数必须保留“已接电源 · 参考电量”字样。
6. 分别在 100%、150% 和 200% 的显示器上检查布局与边缘。逻辑材质图按 DPI 放大，内容层按目标 DPI 单独绘制；跨屏时重新布局并更新色散偏移。
